# Raposity – Rap trifft auf Code / Rap meets Code

---

## German Version – Deutsch

**Raposity** ist ein offenes Webprojekt, das Rap und Programmierung vereint. Es bietet eine interaktive Plattform, auf der Nutzer:innen ihre eigenen Rap-Bars eingeben und eine Echtzeitanalyse ihres Textes erhalten. Das Ziel ist es, Kreativität und kulturellen Ausdruck digital sichtbar zu machen – ein Statement, das Technik, Kunst und Emotionen zusammenbringt.

### Projektidee

Raposity ist mehr als nur ein Code-Snippet:  
Es ist ein digitales Mic, das jedem eine Stimme gibt. Unsere Plattform lädt dazu ein, eigene Texte zu verfassen, den Flow zu testen und den Vibe des Geschriebenen zu spüren.  
Die Analyse teilt die Stimmung in vier Kategorien ein:
- **Aggressiv:** Texte mit kraftvollen, konfrontativen Worten (z.B. "Krieg", "Kampf", "Hass").
- **Emotional:** Zeilen mit Begriffen wie "Liebe", "Herz" oder "Sehnsucht".
- **Flex / Ego:** Bars, die von Reichtum, Status oder Selbstbewusstsein erzählen.
- **Dunkel / Melancholie:** Zeilen, die Themen wie Nacht, Einsamkeit oder Leere beinhalten.

### Features

- **Echtzeitanalyse:** Nutzer:innen geben ihre Rap-Bars ein – und erhalten sofort eine Stimmungseinschätzung.
- **Responsive Design:** Optimiert für Desktop und mobile Endgeräte, um jederzeit und überall kreativ zu werden.
- **Offene Plattform:** Als Open-Source-Projekt lädt Raposity Entwickler:innen und Künstler:innen ein, eigene Features, Beats, Visuals oder weitere Analyse-Tools beizusteuern.
- **Kulturelles Statement:** Zeigt, dass Technik nicht nur funktional, sondern auch kreativ und emotional sein kann.
